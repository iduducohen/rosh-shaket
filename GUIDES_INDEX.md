## 🔄 Development Workflows

### Browser Development
See: [BROWSER_ACCESS_GUIDE.md](BROWSER_ACCESS_GUIDE.md)

Steps:
1. `npm start` - Starts dev server
2. Open http://localhost:5051
3. Edit code
4. See changes auto-refresh
5. Use F12 for DevTools

### Android Development
See: [ANDROID_STUDIO_SETUP.md](ANDROID_STUDIO_SETUP.md)

Steps:
1. `npm run build:prod` - Build for Android
2. `npx cap sync android` - Sync with native
3. `npx cap open android` - Open in Studio
4. Create/launch emulator
5. Click Play to deploy

### Testing Workflow
See: [TESTING.md](TESTING.md)

Steps:
1. Write tests (`.spec.ts` files)
2. `npm run test` - Run tests
3. `npm run test:watch` - Watch mode
4. `npm run e2e:open` - Interactive E2E
